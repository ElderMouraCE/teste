# teste

Repositório de testes de Elder Moura Consultoria Empresarial.

## Conteúdo

| Arquivo | Descrição |
| --- | --- |
| `index.html` | Página HTML inicial (ainda vazia, apenas a estrutura básica). |
| `Nova pasta/Compras x vendas CG html.txt` | Código HTML do relatório **Hortifruti CG – Controle de Estoque**, que compara compras e vendas e aponta discrepâncias, com busca e exportação para CSV. |

## Como visualizar o relatório

1. Baixe o arquivo `Nova pasta/Compras x vendas CG html.txt`.
2. Renomeie a extensão de `.txt` para `.html`.
3. Abra o arquivo no navegador (é necessária conexão com a internet para carregar os estilos e ícones).
